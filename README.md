# AstrBot 打卡积分商店

<img src="logo.png" width="160" height="160" alt="积分商店图标">

当前版本：**v1.3.0**。适用于 AstrBot `>=4.16,<5`，Python 3.10+，依赖 `Pillow>=9.0`。

每天打卡获得积分，再用积分兑换商品；管理员通过 AstrBot 后台管理商品和兑换记录。插件负责记账、图片展示和通知，商品或权益由管理员实际发放。

## v1.3.0 更新

- 后台界面沿用图标的蓝、奶白与金色配色，重新整理导航、概览、表单和预览区；优化亮暗主题、手机窄屏、键盘切换及弹窗反馈。
- 商品保存后图片上传失败时保留商品 ID、排序和表单；再次保存更新同一商品，避免重复新增。
- 后台预览使用真实商品图并排除下架商品，可搜索选择真实用户，按其余额和限购记录展示；默认明确标为「模拟用户，0 积分」。
- 流水日期及分钟结束条件包含末尾亚秒记录，横杠、斜杠日期行为一致；页面时间、筛选和 CSV 导出统一按北京时间 UTC+8。
- 自定义奖励列表和权重逐项校验非负整数，错误输入提示具体位置并阻止保存；不再丢弃非法项或截断小数。
- 更新蓝发 Q 版看板娘图标，保留「积分商店」铭牌、签到卡与积分金币。
- 「未带前缀的指令提示」继续默认关闭，退款防重、改价重新确认与严格引用校验继续保留。

历史版本的变更记录见 `CHANGELOG.md`。

## 安装与升级

1. 在 AstrBot 后台的插件管理中上传 `astrbot_plugin_checkin_shop-v1.3.0.zip`，或使用 `metadata.yaml` 中的仓库地址安装。
2. 重载插件；打开插件详情中的管理页，添加商品并设置打卡规则。
3. 升级前建议备份 `data/plugin_data/astrbot_plugin_checkin_shop/`。升级沿用原有积分、商品和兑换数据。
4. 未带前缀的指令提示默认关闭。如果需要恢复提醒，到插件配置页或插件页「展示设置」开启「未带前缀的指令提示」。

## 常用指令

下面以默认前缀 `/` 举例。如果 AstrBot 的唤醒前缀是 `+`，请发送 `+打卡`、`+商店`；插件的 `display_prefix` 也可填 `+`，使回复文案与实际操作一致。

| 指令 | 别名 | 功能 |
| --- | --- | --- |
| `/打卡` | `/签到` | 每天一次，获得积分 |
| `/商店` | — | 查看积分与可兑换、暂不可兑换的商品 |
| `/我的积分` | `/积分` | 查看余额、连签和打卡记录 |
| `/积分榜` | `/排行榜` | 查看本平台或全平台排行 |
| `/兑换商品` | `/兑换` | 不带参数查看商品编号菜单 |
| `/兑换商品 1` | `/兑换 1` | 按编号发起兑换，也支持商品名称或部分名称 |
| `/绑定邮箱 邮箱` | `/我的邮箱` | 绑定收件邮箱；不带参数查看，填 `解绑` 清除 |
| `/商店帮助` | `/打卡帮助` | 查看指令、当前规则和兑换步骤 |

指令与参数之间需留空格。@ 机器人或私聊时，是否需要前缀由 AstrBot 自身的唤醒规则决定。关闭提醒只让本插件的提示保持静默，不会把裸关键词变成有效指令，也不影响其他插件或大模型处理消息。

## 兑换流程

1. 用户发送 `/兑换 1` 或 `/兑换商品 商品名`。
2. 机器人显示商品、所需积分及 `SHOP-XXXXXX` 确认编号。
3. 用户**引用最新的那条确认消息**回复「是」或「否」，默认 60 秒内有效。
4. 确认成功后再次检查价格、余额、库存和限购，扣分、扣库存并建立「待发放」记录。
5. 管理员实际发放后，在后台标记「已发放」，机器人发送通知；开启 SMTP 后同时尝试发送邮件。

注意：

- 确认期间价格发生变化时，当前请求作废，请重新发送兑换指令。
- 引用必须能核对到本次确认编号。当前普通发送流程不保存平台发送回执；适配器若只提供引用消息 ID、不提供引用正文，插件会拒绝确认，不能只凭发送者是机器人就扣分。
- 只接受当前选中的最新待确认请求；连续发起多笔兑换时，请引用最新提示。重载插件会清空尚未确认的请求，已完成兑换记录继续保留。
- 「取消并返还」只返还一次积分和库存。已取消记录不能恢复；需要再次兑换时请新建兑换。
- 删除兑换记录只清理历史，不退款、不回补库存；删除待发放记录需明确强制操作。限购根据现存未取消记录统计，删除历史会影响限购计数。

## 后台管理

管理页嵌入 AstrBot WebUI，通过宿主插件页接口通信，不是独立的用户网页商城。管理页包括：

- 商品管理：名称、价格、库存、限购、分类、说明、图片、排序和上下架；图片上传失败后可保留表单重试。预览前可搜索用户，选择真实用户或模拟零积分视角。
- 打卡规则：固定积分、随机区间、自定义列表及权重、连签奖励。列表最多 30 项，每项必须是非负安全整数（不超过 9007199254740991）；非空权重需与积分列表等长且至少一项大于零，空权重表示等概率。
- 用户积分：搜索用户、查询余额、手动调整并记录流水。
- 兑换记录：标记发放、取消并返还、删除历史记录。
- 账单流水：按类型、关键词和日期筛选，查看收支汇总，导出 CSV；显示与筛选统一使用北京时间 UTC+8。日期与分钟结束条件包含其完整一天或一分钟，精确时间戳保留端点语义。
- 展示设置：商店标题、副标题、显示前缀、裸指令提示开关、榜单范围和长度、确认超时及每日重置小时。

## 主要配置

| 配置键 | 默认值 | 说明 |
| --- | --- | --- |
| `bare_command_hint_enabled` | `false` | 未匹配的裸指令是否发送前缀提示 |
| `display_prefix` | `/` | 仅改变提示和卡片上的指令写法，不修改 AstrBot 唤醒规则 |
| `checkin_mode` | `fixed` | `fixed` / `random` / `custom` |
| `checkin_fixed` | `10` | 固定模式每次奖励 |
| `checkin_random_min` / `checkin_random_max` | `5` / `20` | 随机积分闭区间 |
| `checkin_custom_points` / `checkin_custom_weights` | `[5,10,20]` / `[]` | 自定义候选分数；空权重表示等概率 |
| `streak_bonus_enabled` | `true` | 是否启用连签奖励 |
| `streak_bonus_every` / `streak_bonus_points` | `7` / `50` | 每连续 7 天额外奖励 50 分 |
| `reset_hour` | `0` | 按北京时间 UTC+8 重置；填 4 表示凌晨 4 点换日 |
| `confirm_timeout_seconds` | `60` | 确认超时，后台支持 10–600 秒 |
| `leaderboard_scope` / `leaderboard_size` | `platform` / `20` | 排行榜范围和人数 |
| `points_scope` | `platform_user` | 目前只实现同平台用户跨群共享；`conversation` 为预留项 |
| `email_enabled` | `false` | 是否启用发放邮件通知 |
| `render_width` | `1080` | 卡片宽度 |
| `render_font_path` | 空 | 空值使用内置中文字体 |

打卡规则和展示设置在配置页、管理页之间同步：只把配置页相对上次同步发生变化的键覆盖进运行数据；管理页保存后回写配置。首次升级时会保留管理页已修改而配置页仍为默认值的设置。

## 邮件通知

在插件配置页填写 SMTP 服务器、端口、加密方式、账号和授权码。SSL 常用 465，STARTTLS 常用 587；可在管理页发送测试邮件。

收件地址优先使用用户绑定邮箱，其次按数字用户 ID 加默认后缀推断（默认 `@qq.com`），最后使用兜底收件地址。邮件失败不撤销发放状态，后台会显示结果。瞬时网络故障或 SMTP 4xx 最多尝试 3 次；认证错误和收件人拒收不反复重试。投递是阻塞 SMTP 在线程中执行，不能保证整封邮件在固定 20 秒内返回。

## 数据与图片

运行数据位于 AstrBot 提供的插件数据目录：

```text
data/plugin_data/astrbot_plugin_checkin_shop/
├── shop.json     # 设置、用户、商品、兑换记录、流水及配置同步快照
├── products/     # 商品图片
└── render/       # 图片缓存
```

积分按 `平台:用户ID` 记账，同平台跨群共享。写入使用单实例异步锁、快照和临时文件原子替换；不支持多个进程共同写同一份数据文件。流水最多保留最近 1000 条，因此汇总与 CSV 导出也只覆盖仍保留的流水。

商店、个人积分、排行榜和帮助图使用 Pillow 与内置 Noto Sans CJK SC 字体本地绘制。文字和图片合并发送；渲染异常时退回文字。缓存按内容及 30 分钟时间桶复用；当前渲染目录不自动清理，长期运行需留意磁盘空间。同一图片路径直接替换文件时，缩略图可能在当前缓存桶内仍显示旧内容。

## 开发验证

```text
python -m pytest

python scripts/build_release.py --out outputs
```

页面检查使用模拟的 AstrBot 插件页接口，默认把截图写入 `work/page-artifacts/`；可用 `PAGE_ARTIFACT_DIR` 指定位置，`PAGE_REVIEW=1` 额外生成各页面复核截图。测试用例覆盖业务、存储、图片渲染、邮件及插件指令接线；完整 AstrBot 和平台适配器仍需在部署环境验收。

发布包默认写入 `outputs/`，打包中间文件写入 `work/temp/`，自检通过后才移入交付目录。
