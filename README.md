# AstrBot 打卡积分商店

<img src="logo.png" width="160" height="160" alt="积分商店图标">

当前版本：**v1.4.0**。适用于 AstrBot `>=4.16,<5`，Python 3.10+，依赖 `Pillow>=9.0`。

每天打卡获得积分，再用积分兑换商品或参加虚构积分玩法；管理员通过 AstrBot 后台管理规则、商品、竞猜和资产。普通商品由管理员发放，特殊道具购买后自动执行权益。

## v1.4.0 更新

- 新增虚构股票、活期积分通、管理员竞猜、自动行情竞猜和刮刮乐，全部默认关闭，管理员在「玩法管理」按模块开启。
- 新增签到增益卡和余额返利卡，按商品类型和参数执行；所有商品可设置每日限购，两类卡分别共享同类每日额度，返利卡另有持久冷却。
- 新增五个聊天入口，扣分操作沿用严格引用确认；行情、规则、商品效果或返利基数变化时重新确认。签到显示基础、连签、道具三部分。
- 新增只读资产详情、竞猜创建/判定/作废、费用与收益流水及 CSV；保留原六个后台入口并新增一个「玩法管理」。
- JSON 数据版本升级前自动备份，旧商品保持普通商品；额度、权益、开奖结果和成功回执独立保存。支持重启恢复确认、离线行情补齐、利息补算及幂等派奖。
- 保留图文商店、上传失败重试、真实用户预览、北京时间筛选、退款防重及默认关闭的裸指令提示。
- 支持新增与编辑股票、独立波动与手续费、停牌买入；聊天行情卡和后台股票选择区均展示真实小时趋势，最多保留最近 7 日行情。
- 签到增益卡确认兑换后即日起生效；后台全部布尔选项统一为滑动开关。兑换记录提示待发放数量，玩法管理仅提示封盘待管理员处理的竞猜，处理后自动更新。
- 商店帮助按玩法开关显示入口；积分通指令兼容带前缀的完整参数，已关闭玩法的原有资产仍可按规则取出或处理。

历史版本的变更记录见 `CHANGELOG.md`。

## 安装与升级

1. 在 AstrBot 后台的插件管理中上传 `astrbot_plugin_checkin_shop-v1.4.0.zip`。
2. 重载插件；打开插件详情中的管理页，添加商品并设置打卡规则。
3. 升级前备份 `data/plugin_data/astrbot_plugin_checkin_shop/`。首次升级数据版本时自动保留 `shop.json.v1.backup.<时间>.json`，余额、库存和兑换记录保留，旧商品不会按名称自动变成道具。备份或迁移失败会停止加载，不重建有效资产文件。
4. 未带前缀的指令提示默认关闭。如果需要恢复提醒，到插件配置页或插件页「展示设置」开启「未带前缀的指令提示」。

## 常用指令

下面以默认前缀 `/` 举例。如果 AstrBot 的唤醒前缀是 `+`，请发送 `+打卡`、`+商店`；插件的 `display_prefix` 也可填 `+`，使回复文案与实际操作一致。

| 指令 | 别名 | 功能 |
| --- | --- | --- |
| `/打卡` | `/签到` | 每天一次，获得积分 |
| `/商店` | — | 查看积分与可兑换、暂不可兑换的商品 |
| `/我的积分` | `/积分` | 查看余额、连签和打卡记录 |
| `/积分榜` | `/排行榜` | 查看本平台或全平台排行 |
| `/兑换商品` | `/兑换` | 不带参数查看商品编号菜单 |
| `/兑换商品 1` | `/兑换 1` | 按编号发起兑换，也支持商品名称或部分名称 |
| `/绑定邮箱 邮箱` | `/我的邮箱` | 绑定收件邮箱；不带参数查看，填 `解绑` 清除 |
| `/商店帮助` | `/打卡帮助` | 查看指令、当前规则和兑换步骤 |
| `/股市` | — | 查看行情；`持仓`、`买入 股票代码 1`、`卖出 股票代码 1`，代码以后台当前股票为准 |
| `/积分通` | — | 查看本金与利息；`存入 100`、`取出 100` |
| `/竞猜` | — | 查看列表；`详情 题号`、`下注 题号 选项 10` |
| `/刮刮乐` | — | 查看奖表；`购买`一张，引用确认后开奖 |
| `/我的道具` | — | 查看签到卡状态、剩余业务日和返利卡冷却 |

指令与参数之间需留空格。@ 机器人或私聊时，是否需要前缀由 AstrBot 自身的唤醒规则决定。关闭提醒只让本插件的提示保持静默，不会把裸关键词变成有效指令，也不影响其他插件或大模型处理消息。

## 兑换流程

1. 用户发送 `/兑换 1` 或 `/兑换商品 商品名`。
2. 机器人显示商品、所需积分及 `SHOP-XXXXXX` 确认编号。
3. 用户**引用最新的那条确认消息**回复「是」或「否」，默认 60 秒内有效。
4. 确认成功后再次检查价格、效果、余额、库存和限购；普通商品建立「待发放」记录，特殊道具自动执行并标记「已发放」。
5. 管理员实际发放后，在后台标记「已发放」，机器人发送通知；开启 SMTP 后同时尝试发送邮件。

注意：

- 确认期间价格、效果、限购或返利基数发生变化时，当前请求作废，请重新发送指令。
- 引用必须能核对到本次确认编号。当前普通发送流程不保存平台发送回执；适配器若只提供引用消息 ID、不提供引用正文，插件会拒绝确认，不能只凭发送者是机器人就扣分。
- 只接受当前选中的最新待确认请求；连续发起多笔操作时，请引用最新提示。未过期请求在重启后恢复，成功回执防止重复扣费、开奖和发放。
- 「取消并返还」只返还一次积分和库存。已取消记录不能恢复；需要再次兑换时请新建兑换。
- 删除兑换记录只清理历史，不退款、不回补库存；删除待发放记录需明确强制操作。原累计限购仍按未取消记录统计；新增每日限购、同类额度、冷却和权益不依赖历史，删除记录不能释放。已发放道具和已开奖交易不能走普通商品退款。

## 积分玩法默认规则

所有玩法使用现有积分，按同平台用户跨群共享。每日额度使用北京时间及「每日重置小时」，按业务日重置。管理员可调整下列参数；启用模块不会自动创建道具商品，需在商品管理选择类型添加。

| 模块 | 初始参数 |
| --- | --- |
| 虚构股市 | ST01 星河科技、ST02 喵喵食品、ST03 云海能源、ST04 像素娱乐，初价均为 100 分/股。整点生成行情，每小时最大 ±2%，相对当日开盘最大 ±10%，最低 1 分；仅整数股。买入本金向上取整、卖出本金向下取整，手续费为成交积分的 1% 向上取整且至少 1 分。每日最多 20 笔，买入含费最多 1000 分。 |
| 活期积分通 | 本金上限 5000 分，日利率 0.05%，从实际存入时刻计息；不足 1 分的整数定点余数持续保留，利息进入可用余额、不复存，离线补算。利率变更前先按旧规则结清。 |
| 积分竞猜 | 管理员题目 2～6 个选项，每人每局一次、5～50 分，每日所有竞猜合计投入最多 100 分。中奖者按投入比例分配奖池的 95%，最大余数法、固定顺序处理零头；回报仅为预计值。作废、无人押中或管理员封盘后 7 天未判时全额退本，不恢复已用每日额度。 |
| 自动竞猜 | 竞猜 ST01 下一整点的涨/跌/平，每小时开局、下一整点前 5 分钟封盘，按实际生成行情结算。停机补齐行情并结算旧局，不补建可下注的历史局。 |
| 刮刮乐 | 每张 10 分、每天最多 3 张；奖项 0/5/10/40/100 分，概率 45%/20%/25%/9%/1%，平均返奖 8.1 分。确认后扣费、固定结果、派彩和次数同事务提交。 |
| 签到增益卡 | 建议售价 50 分；兑换确认成功后即日起连续 7 个业务日，基础签到 2 倍，每日额外最多 20 分。只放大基础奖励，不放大连签奖励；漏签不补天，生效中的卡不能重复购买。 |
| 余额返利卡 | 建议售价 300 分；兑换前可用余额的 15% 四舍五入返还，封顶 350 分，默认净收益最多 50 分；返还低于售价则拒绝。每天同类最多 1 次并冷却 168 小时，存款、持仓和竞猜投入不计入基数。 |

两类卡各自默认共享每日 1 次额度，换名称、换编号不能绕过。道具金额用四舍五入（半入），费率用万分比和整数定点运算。已购卡与已接受竞猜保留当时规则。关闭模块停止新参与，仍可取出本金、卖出持仓、处理已有竞猜及兑现有效签到卡。

在「玩法管理 → 虚构股市 → 股票自定义」新增股票代码、名称和初价，可单独填写每小时/每日波动与手续费；留空沿用全局值。已有股票的初价不支持改写，停牌只关闭买入，持仓仍可卖出。已有持仓、成交记录或未结算竞猜的股票不能删除；纯行情快照不会阻止删除。自动竞猜可选择当前任意股票。

签到卡按北京时间和每日重置小时计算业务日：购买确认成功即生效，购买当日计入有效天数；如果当日已经签到，不追补当日加成。旧卡已保存的起止日期继续按原记录执行。

## 后台管理

管理页嵌入 AstrBot WebUI，通过宿主插件页接口通信，不是独立的用户网页商城。管理页包括：

- 商品管理：名称、价格、库存、累计与每日限购、分类、图片、排序和上下架；普通商品、签到增益卡、余额返利卡采用明确类型和效果参数。图片上传失败可保留表单重试；预览支持真实用户或模拟零积分视角。
- 打卡规则：固定积分、随机区间、自定义列表及权重、连签奖励。列表最多 30 项，每项必须是非负安全整数（不超过 9007199254740991）；非空权重需与积分列表等长且至少一项大于零，空权重表示等概率。
- 用户积分：搜索用户、查询余额、手动调整并记录流水；资产详情展示存款、持仓、竞猜占用积分及道具。积分榜仍只按可用积分排名。
- 兑换记录：标记发放、取消并返还、删除历史记录。
- 账单流水：按类型、关键词和日期筛选，查看收支汇总，导出 CSV，包含玩法来源、费用及收益明细；本金转移不计为新增收益。汇总收入/支出仍是可用余额现金流。显示与筛选统一使用北京时间 UTC+8。日期与分钟结束条件包含其完整一天或一分钟，精确时间戳保留端点语义。
- 展示设置：商店标题、副标题、显示前缀、裸指令提示开关、榜单范围和长度、确认超时及每日重置小时。
- 玩法管理：按模块启停，设置费率、额度和数字奖表，创建、判定或作废管理员竞猜。`/shop/economy/*` 接口只负责管理和资产查询，不接受浏览器指定任意玩家交易。

## 主要配置

| 配置键 | 默认值 | 说明 |
| --- | --- | --- |
| `bare_command_hint_enabled` | `false` | 未匹配的裸指令是否发送前缀提示 |
| `display_prefix` | `/` | 仅改变提示和卡片上的指令写法，不修改 AstrBot 唤醒规则 |
| `checkin_mode` | `fixed` | `fixed` / `random` / `custom` |
| `checkin_fixed` | `10` | 固定模式每次奖励 |
| `checkin_random_min` / `checkin_random_max` | `5` / `20` | 随机积分闭区间 |
| `checkin_custom_points` / `checkin_custom_weights` | `[5,10,20]` / `[]` | 自定义候选分数；空权重表示等概率 |
| `streak_bonus_enabled` | `true` | 是否启用连签奖励 |
| `streak_bonus_every` / `streak_bonus_points` | `7` / `50` | 每连续 7 天额外奖励 50 分 |
| `reset_hour` | `0` | 按北京时间 UTC+8 重置；填 4 表示凌晨 4 点换日 |
| `confirm_timeout_seconds` | `60` | 确认超时，后台支持 10–600 秒 |
| `leaderboard_scope` / `leaderboard_size` | `platform` / `20` | 排行榜范围和人数 |
| `points_scope` | `platform_user` | 目前只实现同平台用户跨群共享；`conversation` 为预留项 |
| `email_enabled` | `false` | 是否启用发放邮件通知 |
| `render_width` | `1080` | 卡片宽度 |
| `render_font_path` | 空 | 空值使用内置中文字体 |

打卡规则和展示设置在配置页、管理页之间同步：只把配置页相对上次同步发生变化的键覆盖进运行数据；管理页保存后回写配置。首次升级时会保留管理页已修改而配置页仍为默认值的设置。

## 邮件通知

在插件配置页填写 SMTP 服务器、端口、加密方式、账号和授权码。SSL 常用 465，STARTTLS 常用 587；可在管理页发送测试邮件。

收件地址优先使用用户绑定邮箱，其次按数字用户 ID 加默认后缀推断（默认 `@qq.com`），最后使用兜底收件地址。邮件失败不撤销发放状态，后台会显示结果。瞬时网络故障或 SMTP 4xx 最多尝试 3 次；认证错误和收件人拒收不反复重试。投递是阻塞 SMTP 在线程中执行，不能保证整封邮件在固定 20 秒内返回。

## 数据与图片

运行数据位于 AstrBot 提供的插件数据目录：

```text
data/plugin_data/astrbot_plugin_checkin_shop/
├── shop.json     # 设置、用户、商品、玩法资产、权益、额度、成功回执、记录与流水
├── products/     # 商品图片
└── render/       # 图片缓存
```

积分按 `平台:用户ID` 记账，同平台跨群共享。写入使用单实例异步锁、快照和临时文件原子替换；不支持多个进程共同写同一份数据文件。流水最多保留最近 1000 条，因此汇总与 CSV 导出也只覆盖仍保留的流水。

玩法每日计数、卡权益、冷却和交易回执独立持久化；历史流水裁剪不会重置这些限制。升级不追溯发放权益，每日商品计数从本版成功交易开始累计。启动、用户交易前和后台每分钟处理到期事项。升级后的数据请勿交给旧版本插件写入；需要回退时停机后恢复升级前完整备份。

商店、个人积分、排行榜和帮助图使用 Pillow 与内置 Noto Sans CJK SC 字体本地绘制。文字和图片合并发送；渲染异常时退回文字。缓存按内容及 30 分钟时间桶复用；当前渲染目录不自动清理，长期运行需留意磁盘空间。同一图片路径直接替换文件时，缩略图可能在当前缓存桶内仍显示旧内容。

```text

```

页面检查使用模拟的 AstrBot 插件页接口，默认把截图写入 `work/page-artifacts/`；可用 `PAGE_ARTIFACT_DIR` 指定位置，`PAGE_REVIEW=1` 额外生成各页面复核截图。测试用例覆盖业务、存储、图片渲染、邮件及插件指令接线；完整 AstrBot 和平台适配器仍需在部署环境验收。
